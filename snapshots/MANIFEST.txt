Subject snapshot manifest
=========================

Every subject is pinned to an exact upstream commit. The human baselines are
cloned from their public repositories at the tags/SHAs below; the agentic
subjects are frozen at the final commit of their generation run and are
distributed in the separate generation bundle (they are not reproducible from
this harness -- see README, "Agentic subjects").

  flask     : analysis scope is src/flask/  (the core package)
  django    : analysis scope is django/urls/ and django/views/  (see subjects.json "include")
  flask_0_1 : maturity control, structural metrics only, no oracle evaluation.
              flask.py at this tag uses Python 2's `except X, e:` syntax (2
              occurrences), a SyntaxError under Python 3 that blocks every
              tool in this pipeline; both are mechanically rewritten to
              `except X as e:` before analysis. See
              snapshots/flask-0.1-patch.md for the exact diff.

Analysis toolchain
------------------
Pinned in requirements-analysis.txt (Radon, complexipy, Bandit, pylint, pytest).
CPD ships with PMD 7.0.0, installed in the Dockerfile. The exact interpreter and
resolved tool versions for the committed results/ are recorded in
logs/environment.txt.
